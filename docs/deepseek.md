# 手机直连 DeepSeek

随手记事直接向 DeepSeek 的 HTTPS API 发送请求。没有电脑代理、Harness、Cloudflare 中转或域名配置。首次保存 API Key 后，正常打开 App 无需重复输入。

## 取得 API Key

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com/)，使用自己的账户登录。
2. 查看 API 账户余额／可用额度，在 API Keys 页面创建 Key。
3. 在随手记事设置中粘贴 Key。默认模型为 `deepseek-flash`，账户不支持时根据开放平台说明选择实际可用模型。
4. 保存后回到对话页，用一条简单请求验证，例如“记一下：明天带充电器”。

API 服务按使用量计费。网页版会员或免费聊天额度不能直接作为 API 余额使用；价格和模型列表以 [DeepSeek 官方文档](https://api-docs.deepseek.com/) 为准。

## 请求与反馈

模型分析消息，给出分类、必要的追问或结构化操作；手机校验日期和字段，再执行本地数据库或 HITA 操作。软件只有实际操作成功后才反馈保存／修改成功。

任务的重要性与紧急性独立于事项类型。DDL、考试、普通待办、备忘与日程有不同字段；信息不足时先追问。可以继续回复“改成备忘”“这个不重要”或“截止时间是晚上十点”，补全或修正当前事项。

离线时可以查看和手动管理本地记录，AI 对话会提示网络问题。失败不会视为成功保存，重试后请核对实际结果。

## 常见问题

| 现象 | 检查方向 |
| --- | --- |
| 鉴权失败 | Key 是否有效、是否多粘贴空格，必要时在开放平台创建新 Key |
| 额度不足 | API 账户可用额度；与网页版额度分开查看 |
| 模型不存在 | 设置中的模型名是否与账户当前可用模型一致 |
| 超时或无法连接 | 手机能否访问官方 API、当前 Wi-Fi／移动数据、服务状态 |
| 分类或日期不准确 | 用后续消息修正，或打开记录编辑页面；AI 判断不应代替核对 |

Key 通过 Android Keystore 加密保存，记录备份不导出 Key。API 请求仍会把当前消息、相关对话和需要查询／编辑的记录内容发给 DeepSeek；请依据实际需要选择输入内容。
