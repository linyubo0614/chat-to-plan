# HITA 兼容版

你已允许维护兼容版并接受常驻通知。本版基于 MIT 授权的 [HIT-A/HITA_Android](https://github.com/HIT-A/HITA_Android)，固定源码提交见 `integrations/hita/upstream.json`。全部新增源码、构建补丁和原始许可证都保存于本仓库，可重复构建；没有修改或推送上游仓库。

下载 Releases 中 `HITA_Planner_3.0.3-planner.2.apk`。这是独立包名 `cn.chatplanner.hita` 的预览版，可以与原版并存；**不要卸载原版**。桌面有课表入口和“对话计划连接”设置入口。后者只在你手动打开时显示界面，后台写入不会打开页面。

## 连接与核对

在连接设置中填写自己的 HTTPS 服务地址和连接口令，开启连接、保存并允许通知。后台维持长轮询，将单次课程或日程写进本地 Room 数据库的独立“对话计划”课表，事务提交并读回核对后向服务端确认。重复交付使用确定的事件编号，避免断网后重复创建；检测到你已手动改动的同编号事件时停止，不覆盖它。

打开 HITA 兼容版切换到“对话计划”课表，检查时间、标题和地点。课程以课程事件保存，普通日程以其他事件保存。目前正文仍保存在助手消息详情中，HITA 事件模型没有对应正文栏。重复规则、指定提醒以及对写入记录的后续修改暂未接入。

常驻通知是保持连接的机制，另有 WorkManager 15 分钟任务作为恢复补充。秒级交付依赖常驻服务在线，补充任务本身不保证低延迟；系统禁止自启动、杀进程或断网仍可能中断，需要在你的 OPPO 上测量。当前未做 OPPO 真机验证。

## 原有数据与后续更新

独立包不能读取原版的私有数据库。请先使用原版已有的导出/备份功能，再在兼容版使用对应导入功能；导出格式、课程备注和提醒是否完整迁移必须用你的实际课表核对，当前没有证明无损迁移。原版和兼容版不会自动互相同步。

今后更新需要将上游新版本合并到本兼容版、重新构建并完成检查，再从本仓库发布。不是安装原版更新就自动获得新功能。兼容版的内置更新只选择本仓库名字以 `HITA_Planner_` 开头的 APK，避免误下载控制 App。正式维护版本还需要固定签名；本次调试预览的签名策略以 Release 说明为准，不能保证跨构建机器覆盖安装。

开发构建：

```bash
python3 scripts/build_hita.py --output /tmp/hita-planner-build --sdk "$ANDROID_HOME" --jdk "$JAVA_HOME"
```

输出目录必须不存在，脚本不会覆盖已有工作区。需要 JDK 21、SDK 36、网络下载 Gradle/Maven 依赖；固定上游源码校验、补丁检查、编译和上游单元测试均由脚本执行。CI 另用 Android 35 模拟器运行本地 Room 写入、响应丢失重试去重、手动修改保护及不支持提醒的拒绝测试；这些测试不代替 OPPO 真机验收。

新版连接入口：HITA 主界面左上菜单 → 对话计划连接；也可在手机对话计划设置中点“打开 HITA 连接设置”。原版 HITA 不含该入口。APK 签名冲突时必须先导出并核对所有课表备份，再卸载重装并导入。
