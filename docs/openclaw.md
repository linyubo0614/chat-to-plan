# 微信 / OpenClaw / DeepSeek

继续使用已经登录的微信 ClawBot，模型按用户选择切换为 DeepSeek。电脑连接中心内置配置和工具安装，无需重新做微信授权。

按 [Windows 操作步骤](windows.md)：启动全部 → 验证并应用 DeepSeek → 安装 / 修复保存工具 → 重启微信助手 → 微信发 `/new`。Key 只在本机密码框填写。默认助手、各助手的独立模型、子助手和已有心跳模型统一为 DeepSeek，清空这些聊天模型的旧回退列表。既有微信渠道、工作区和其他工具保留。

程序将 `chat_planner_record` / `chat_planner_status` 加入全局以及各助手的工具允许列表。广泛禁止所有插件的策略不会被悄悄删除，连接检查会报告该阻塞。插件只为 OpenClaw 认定的所有者提供保存工具；微信联系人授权与渠道的所有者配置需要保持正确。当前验证使用官方 OpenClaw 2026.10.1；旧版不支持批量配置时会停止，反馈版本号后处理。

记录工具由当前 DeepSeek 助手整理结构，后端保存时不再请求第二次模型。待办和备忘保存到本程序，课程和日程交给 HITA。模型回复“已记下”必须以工具真实返回为依据。程序不承诺未经工具执行的文字已经保存。

## WSL

电脑软件当前自动配置 Windows 原生 OpenClaw。若微信助手运行在 WSL，请先说明这一点，保留原 WSL 配置。在原 WSL 中安装 Windows 包里的 openclaw 插件，使用手机可访问的 HTTPS 地址和 `/mnt/c/.../data/api-token`。WSL 与 Windows 的本机地址可能不同，不能直接照搬 127.0.0.1。不要把 Key 或完整渠道配置发送到聊天。

## 交付与限制

验收三条消息见 Windows 说明。日期按 Asia/Shanghai；缺失日程开始/结束时间先追问。稳定 operation_id 用于网络重试去重；同编号不同内容返回409，不以新编号盲目重复保存。纯闲聊和知识问答不记录。

planner written 表示数据库已保存；HITA written 表示手机连接端报告写入并读回。blocked 是等待，delivering 是处理中。重复课程、指定提醒和微信修改已有 HITA 日程尚未实现；事件可在 HITA 本地编辑。真实微信和 OPPO 显示仍需本地验收，原生 OpenClaw 模拟模型测试不等于实际微信账号联调。
