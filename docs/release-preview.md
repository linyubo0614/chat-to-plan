# 0.7.2：扫码、截图与自定义域名修复

## 这次修改了什么

- 移除手机配对页的禁止截屏标志；配对、设置和其他 App 页面允许截屏。
- 扫码改为配对页内相机预览，不再跳转到扫码库的独立 Activity。
- 明确申请相机权限，处理权限拒绝和相机启动失败，提供“打开相机权限设置”与粘贴链接入口，失败时保留配对页面。
- 配对前先检查 `/healthz`；区分手机 DNS／HTTPS／超时、电脑离线、无效地址、过期二维码和本机保存失败。
- 配对响应等待时间调整为 45 秒，覆盖中转最多 40 秒的等待窗口。
- Windows 增加“自定义域名（可选）”与“保存入口”。支持把自有域名绑定到原 Worker，重启和更新中转后保留入口；可清空恢复原 workers.dev 地址。
- 补充在哪里购买域名、接入 Cloudflare DNS、绑定 Worker，以及手机不开 VPN 验证的完整步骤。

## 下载与使用

手机安装 **chat-planner-debug.apk（0.7.2）**；电脑完整解压 **chat-planner-windows.zip**，不要只下载一个 EXE。退出旧电脑程序，保留原来的整个 `data` 文件夹，再更新程序文件。Harness 不需要重新安装，HITA 仍是可选扩展。

扫码时允许相机权限；拒绝权限也可粘贴链接。可随时截屏，不再因配对页的隐私标志被限制。

预览 APK 使用调试签名，跨构建可能无法覆盖旧安装。若提示签名不兼容，先确认未保存草稿已保存或另行记录，再处理重装。已保存到电脑数据库的任务、备忘和重要日期应保留电脑 `data`；不要为本次更新卸载有未备份课表的 HITA。

## 手机不开 VPN 时连不上怎么办

如果手机开启 VPN 能访问 `/healthz`，关闭后打不开，当前 workers.dev 地址在该网络下不可达；这与普通上网是否正常不同。仅修复扫码或增加超时不能解决域名不可达。

可以在腾讯云或阿里云注册自己的域名，把 DNS 接入已部署中转的 Cloudflare 账号，再将 `planner.你的域名` 绑定到原 Worker。新版电脑程序可通过“保存入口 → 配置 / 更新免费中转”完成 Worker 自定义域名绑定。

**先在手机关闭 VPN、分别使用 Wi-Fi 和移动网络访问自定义域名的 `/healthz`，返回 `{"status":"ok"}` 后再使用新二维码配对。** 更换域名不保证所有网络都可达，需以自己的手机实测为准。第一次换入口需要重新配对，之后正常重启无需重复扫码。
