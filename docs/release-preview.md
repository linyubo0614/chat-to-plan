随手记事 0.8.0 预览版：转为手机本地使用，不再需要电脑、Cloudflare、域名、Harness 或微信／QQ机器人。

### 本次调整

- 打开 App 直接进入 DeepSeek 对话，统一聊天、计划、备忘和设置的简约界面。
- 手机直连 DeepSeek API，一次保存自己的 Key；支持分类反馈、信息不足时连续追问，以及自然语言新增、查询、修改和删除。
- 任务、备忘、DDL、考试和本地日程保存在手机 SQLite，断网可手动管理；加入本地提醒与 JSON 备份、旧电脑数据库导入。
- HITA 改为可选同机授权接口，支持查询和编辑单次课程／日程，无需网络配对或常驻中转。
- 继续允许截屏；同次发布的两款 APK 在同一 CI 作业中使用匹配测试签名，私钥不进入仓库或下载产物。
- 移除废弃电脑服务、中转、MCP／IM接入和对应依赖、脚本、测试；重写 README 与使用说明，保留 Git 历史和旧发布。

### 下载与使用

- `chat-planner-debug.apk`：必需，Android 8.0 及以上。
- `HITA_Planner_*.apk`：可选 HITA 兼容版，使用本地接口时安装同次发布的版本。
- `SHA256SUMS`：校验下载文件。

AI 理解需要手机联网访问 DeepSeek，并按自己的 API 账户计费。第一次在设置保存 Key；其余记录管理无需电脑。未安装 HITA 不影响核心功能。

### 升级注意

不同 CI 构建的预览 APK 可能采用不同测试签名，不能保证覆盖安装。先导出／保留记录备份和 HITA 课表备份，再处理重装。旧电脑版停止服务后，可将 `data/assistant.db` 复制到手机导入；不要删除旧文件直到核对完成。

本地通知受 Android 权限与省电策略影响，可能延后。重要事项请同时核对系统日历提醒。CI 测试密钥仅在临时构建环境使用；正式发行需使用开发者自己的私有签名。

产物来源须通过对应源提交的完整 CI；真实 DeepSeek 账户响应、厂商手机后台提醒和个人 HITA 数据仍需实机核对。
