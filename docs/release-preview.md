安卓控制端预览版，可配置后端地址、DeepSeek API Key 和模型，开关消息处理，并发送消息。

0.2.0 新增消息历史、分类和时间查看、失败分析重试，以及待写入事项的修改、补充时间和取消。日期通过选择器填写；更新检查记录版本，避免覆盖另一处的修改。断网后可继续发送上次未确认的消息，沿用原消息编号去重。

新增功能需要配套0.2.0后端；App 中的修改只作用于助手里的记录。

下载 Assets 中的 `chat-planner-debug.apk` 安装。需要另外部署仓库中的后端；仅安装 APK 不会自动创建微信或 QQ 好友，也不会直接写入番茄计划或 HITA。

尚未完成：真实微信客服账号接入、QQ 接入、番茄计划自动写入，以及原版 HITA 的完全静默写入。原版 HITA 尚未找到可用的公开写入接口。未做 OPPO 真机验收。

附件由本次 GitHub 发布工作流构建。只有后端测试、Android APK 构建和静态检查全部通过，才会发布安装包；发布前还会验证 APK 签名。`SHA256SUMS` 用于校验下载文件。

此版本使用调试签名，仅供预览测试。不同构建机器的调试签名可能不同；如已安装仓库 downloads 中的旧测试包，安装本包可能需要先卸载旧包，卸载会清除应用内配置。正式发布需要固定的正式签名。
