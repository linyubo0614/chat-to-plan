# 验证范围

主分支采用手机本地架构，旧 Python 后端、Windows 程序、微信／QQ插件和 Cloudflare 中转测试已随实现移除。旧版本记录可在 Git 历史和 Releases 查询。

## 自动检查

| 检查 | 覆盖内容 |
| --- | --- |
| Android 构建与 Lint | 主 APK、资源、清单和静态检查 |
| Android 模拟器测试 | 真 SQLite 保存／编辑、模拟 AI 的分类与连续追问、重试去重、聊天与页面、备份及截图许可 |
| HITA 构建与上游测试 | 固定上游提交、补丁与 overlay 可复现构建 |
| HITA 模拟器测试 | 真 Room 数据库操作、两款 App 的本地服务通信 |
| 发布校验 | 精确源提交 checks 成功、两包 APK 签名一致、SHA-256 文件 |

模拟 API 测试不代表所有真实模型回答都正确。测试不使用个人 Key，不声称已验证任何用户的账户额度、私有 HITA 数据或真实手机的后台提醒。

## 使用前应核对

首次实机使用时，发送一个简单记录请求，检查对话反馈与计划页面一致；再测试连续追问、修改、删除和 JSON 导出／导入。启用提醒后锁屏等待一次通知，检查自己的系统通知与省电设置。启用 HITA 后先创建一条测试日程，核对后修改和删除。

发布工作流只使用已通过完整检查的源提交产物；检查失败时不应发布或宣称测试通过。CI 具体结果以 [GitHub Actions](https://github.com/linyubo0614/chat-to-plan/actions) 为准。
