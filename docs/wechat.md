# 微信客服接入

当前选择官方微信客服会话，不依赖公众号聊天或个人微信非官方机器人。官方文档入口：[微信客服开发文档](https://kf.weixin.qq.com/api/doc)。

## 开通前确认

你目前没有企业微信主体。先在企业微信/微信客服官方后台核对个人或组织的注册资格、主体认证要求，以及使用 API 所需的开通条件。以当前后台说明为准；本项目不承诺个人注册必然可以使用全部接口，也不替你创建或认证主体。

确认客服会话的首次进入方式、微信会话列表的保留行为、名称/头像规则，是否符合日常便捷要求。平台对名称和标识可能有审核要求，不能假定一定允许直接使用 DeepSeek 品牌。

## 配置

1. 在后台创建客服账号，启用开发接口，取得 CorpID、客服 Secret。
2. 为部署服务准备可公开访问的 HTTPS 域名。
3. 在服务端配置回调 Token、43 字符 EncodingAESKey；在后台填写同样的值及 `/wechat/callback` 地址。
4. 完成后台 URL 验证，开启消息/事件回调，按后台要求配置可信 IP 等条件。
5. 通过官方允许的方式获得自己的 `external_userid`，配置 `WECHAT_ALLOWED_USERS` 后重启服务。不要为方便开放所有客户。
6. 自己进入客服会话发送测试消息，核对接收、DeepSeek 分析和回复三个独立结果。

回调只验签、解密和持久化事件，不在回调响应前等待 DeepSeek。后台线程调用 `kf/sync_msg` 分页拉取消息，按用户白名单过滤，持久化游标。结果通过 `kf/send_msg` 回复。

微信对回复时限、发送条数、消息类型等有限制，以官方规则为准。当前只处理文字，图片、语音、文件不进入分析。微信 API 的权限、token 过期与发送窗口错误会反映为失败；不能承诺所有场景均能主动推送。

目前协议通过模拟测试，未取得真实主体与凭据，因此**没有完成真实微信会话联调**。
