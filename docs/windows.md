# Windows 11：先验证一条真实记录

下载 Releases 的 `chat-planner-windows.zip`，解压到例如 `C:\ChatPlanner`。后续更新请先备份整个 `data` 文件夹，覆盖程序文件时保留它；不要把备份上传到 GitHub。

## 先做番茄计划授权验证

1. 安装 [Python 3.12](https://www.python.org/downloads/windows/)（安装时勾选 Python launcher）。Windows 11 自带 Edge 即可。
2. 双击 `windows\start-assistant.cmd`。第一次下载依赖需要网络；出现 `Uvicorn running on http://127.0.0.1:8000` 后保持这个窗口打开。
3. 双击 `windows\test-tomato.cmd`。在它打开的**番茄计划官网**登录，进入清单页，然后回到命令窗口按回车。密码只填写在官网。
4. 它会创建“对话计划授权验证”测试备忘和“对话计划测试”分类，并重新读取核对。请打开手机番茄计划刷新，确认两者出现。此测试不会修改或删除原有记录；验证后可手动删除测试记录。

请先反馈第 4 步是否成功以及屏幕上的错误文字，**不要发送密码、浏览器文件、连接口令或 API Key**。目前已核对官网公开网页的同步调用，但云环境没有你的登录状态，因此尚未验证真实账号写入和手机同步。

登录状态只保存在这台电脑的 `data\tomato-browser`；浏览器调用官网自身的授权和同步逻辑。它不是官方承诺开放的 API，网页改变或登录过期可能使交付暂停。看到失败提示时，先检查测试记录是否已出现，再重试；同一账号的重试沿用相同记录编号。

## 第 3 步没有打开浏览器或窗口闪退

请下载更新后的 `chat-planner-windows.zip`。先停止已有服务及番茄连接窗口，备份 `data`，将新包中的程序文件覆盖到原文件夹，保留原有 `data` 和 `.venv`，然后重新启动服务并双击 `windows\test-tomato.cmd`。不需要重新安装手机 APK。

新版会显示清单读取、记录提交和读回核对阶段，以及失败原因和数字返回码；启动器会显示退出码，即使依赖缺失或 Edge 无法启动也会停留，等待按键关闭。请把窗口中错误文字反馈给开发者，不要发送密码、连接口令、API Key 或浏览器文件。不要同时运行测试和同步窗口；它们使用同一个本地浏览器配置。

如果旧版窗口仍然闪退，可以在解压目录的文件资源管理器地址栏输入 `cmd`，按回车后运行 `cmd /d /k windows\test-tomato.cmd`。这样即使旧脚本报错，窗口也会保留。只检查 Edge 能否启动而不登录或写入时，可运行 `windows\test-tomato.cmd --check-browser`。

## 再连接手机

1. 服务窗口保持打开，双击 `windows\start-test-link.cmd`。如果提示未安装 cloudflared，按提示在终端执行 `winget install --id Cloudflare.cloudflared --exact`，完成后重新运行。
2. 这个窗口输出一个 `https://…trycloudflare.com` 地址。将其填入对话计划控制 App 的服务地址。双击 `windows\copy-connection-token.cmd`，将剪贴板里的口令私下传到自己的手机，填入 App 的连接口令。
3. 在控制 App 中连接、保存 DeepSeek Key、开启功能。也可以双击 `windows\configure-deepseek.cmd`，在本机隐藏输入 Key。模型调用会消耗你的 DeepSeek 额度。
4. 双击 `windows\start-tomato-sync.cmd`，按提示确认登录，保持浏览器和此窗口运行。浏览器可以最小化。在控制 App 的“消息与事项”发送一条单次备忘，检查官网、手机番茄计划和任务的“已确认写入”状态。
5. 安装 [HITA 兼容版](hita.md)，在桌面“对话计划连接”入口填入相同的 HTTPS 地址和口令，开启连接并允许通知。在 HITA 中选中“对话计划”课表；发送包含明确开始、结束时间的单次日程，核对事件。

临时地址只用于联调：重启隧道会改变，可能有速度或可用性限制。服务仅监听本机；不要把 8000 端口直接裸露到公网。已有独立服务器也可使用自己的 HTTPS 地址。

## 微信接入

企业微信主体和微信客服开通后，再按 [微信接入说明](wechat.md)配置。`windows\configure-wechat.cmd` 可在本机输入凭据，使用 Windows 当前用户的 DPAPI 加密保存，重启服务生效。白名单为空时拒绝全部用户消息，需要取得并填写自己的 `external_userid`。

正式微信回调需要固定 HTTPS 地址；如企业微信后台要求可信 IP，也需要固定的公网出口 IP。临时隧道解决入站访问，**不会固定家庭网络的出口 IP**。届时根据控制台实际要求选择固定域名的命名隧道或云服务器，再完成平台回调、消息及回复联调。仅注册企业微信、安装 APK 不等于微信入口已开通。

这里提供的是可运行脚本，不会远程安装你的电脑，也没有自动注册或购买任何服务。CI 另行检查 Windows 依赖、服务测试、PowerShell 语法及 DPAPI；你的电脑上的浏览器登录和 OPPO 真机操作仍需本地验收。

## 低延迟和停止

HITA 使用用户开启的常驻通知和最长 25 秒的长轮询：任务一产生就唤醒等待，不是每 25 秒才检查一次。正常在线时重连之间的空档约 1 秒；失败采用 3–30 秒退避。番茄连接端同样等待服务通知。DeepSeek 生成、平台网络和手机后台调度决定端到端耗时，不能保证所有消息都在 1 秒完成。

关闭控制 App 的功能开关会暂停新分析和新任务领取；已经提交的写入可能完成。关闭 HITA 的连接开关会停止常驻服务；正在提交的写入也可能完成。电脑窗口使用 Ctrl+C 停止。

当前只自动写入没有追问、没有重复规则和指定提醒的单次事项。重复课程、指定提前提醒、对已写入记录的修改和撤销暂未实现；这些任务会保留并说明原因，不会假装写入成功。
