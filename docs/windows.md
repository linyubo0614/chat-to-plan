# Windows 11：对话计划电脑连接中心

下载本次 Release 的 **chat-planner-windows.zip**，解压后双击 **ChatPlanner.exe**。程序自带服务运行环境，无需安装 Python，无需挂多个终端。也可单独下载 ChatPlanner.exe，它内置微信保存工具。

旧版更新：先关闭旧 start-assistant、start-test-link 和其他旧助手服务窗口；保留原来整个 `data` 文件夹，将新版放在原 ChatPlanner 文件夹运行。不要同时启动旧脚本和新软件。你原来单独运行的 OpenClaw 可以由程序识别复用；不要关闭微信授权文件或重新扫码。

## 一次配置

1. 点“启动全部”。电脑服务、手机连接通道和微信助手在后台运行。缺少 Cloudflare 时点“安装连接组件”，完成后再次启动。
2. 手机“对话计划 → 设置”，填电脑窗口显示的 HTTPS 地址。点电脑的“复制连接口令”，私下传到手机填写，点“连接并读取设置”。自动处理开关开启后点“保存设置”。
3. 在电脑软件的密码框填写 **DeepSeek API Key**，点“验证并应用 DeepSeek”。程序验证 Key 和实际工具调用能力，将默认助手、每个助手单独模型及子助手设为 `deepseek/deepseek-chat`，清空这些位置的旧回退模型；同步设置本程序的备用分析模型。验证会发一次很短的 DeepSeek 模型请求。
4. 点“安装 / 修复保存工具”，再点“重启微信助手”。工具同时追加到全局与每个助手自己的允许列表。若原 OpenClaw 没有安装成后台服务，关闭它原来的窗口，然后在本软件点“启动全部”。
5. 微信发 `/new` 开始新会话，避免旧会话保留 GPT 模型选择，再测试下面三条消息。

Key 只在自己的电脑填写，不通过聊天发送。OpenClaw 使用受保护的本机 `data/openclaw-deepseek.json` 文件读取 Key；本程序的 Key 加密保存。已有微信渠道和登录凭据保留。程序不会重新登录微信，也不会自动升级 OpenClaw。安装器需支持批量配置和插件运行时检查；版本不兼容会停止并显示提示。WSL 安装见 [OpenClaw 说明](openclaw.md)。

## 验收

- 微信发“帮我记下明天交高数作业，重要、不紧急”。手机点“日历”，选明天，查看“安排时间”象限。
- 微信发“记在女朋友分类：她喜欢茉莉花茶”。手机“分类备忘”查看对应分类。
- 微信发“帮我加到 HITA：明天下午三点到四点上高数，二教301”。HITA 兼容版连接开启后核对事件。

点“连接检查”会分别显示电脑服务、HTTPS 通道、保存工具、默认模型、最近收到的微信工具调用和 HITA 连接时间。工具加载成功不等于微信已经调用；“尚未收到”时不要认为已经写入。点“写入手机测试备忘”可以单独检查电脑到手机，生成一条可删除的连接测试备忘。

## 手机与 HITA

手机三个独立页面：“每日任务”显示所选日期的四象限；“日历”显示整月，点击日期打开每日任务；“分类备忘”支持分类和搜索。可以截屏。首次打开会请求系统添加桌面图标；OPPO 桌面可能需要确认。设置中可以再次点“添加桌面图标”；系统不支持时在应用列表长按并拖到桌面。

手机设置中点“打开 HITA 连接设置”直接进入兼容版的连接页。新版 HITA 也可从主界面左上角菜单 → “对话计划连接”进入，原版 HITA 不含此入口。填写同一 HTTPS 地址、口令，开启连接并允许通知；选“对话计划”课表核对事件。原有 HITA 本地事件编辑保留；微信修改已写入事件仍未实现。

临时 HTTPS 地址在连接通道重启后变化，需要在手机两个 App 更新。电脑软件保持运行即可，可以最小化；关闭会停止它自己启动的服务，已经独立运行的 OpenClaw 不会被强制结束。

## 更新和备份

预览 APK 的签名与旧版本可能不同。先保存未确认草稿；HITA 更新若提示签名冲突，必须先用 HITA 的导出功能备份所有课表、核对备份可用，再卸载安装并导入。电脑停止服务后备份整个 data；服务器日历和备忘不会随手机 App 卸载删除。不要直接卸载有未备份数据的 HITA。

有问题先点连接检查，反馈检查结果和 OpenClaw 版本号；不要发送 Key、口令、二维码、完整配置或 data 文件。
