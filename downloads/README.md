# 调试安装包

[下载对话计划 0.1.0 调试 APK](https://github.com/linyubo0614/vibecoding_test_01/raw/refs/heads/main/downloads/chat-planner-0.1.0-debug.apk)

这是从当前安卓源代码构建的调试包，已通过签名校验；需要连接你自己的 HTTPS 服务端，尚未进行 OPPO 真机验证。不是微信/QQ 或目标软件自动写入已经完成的成品。

支持服务端连接、分析开关、DeepSeek API Key/模型配置和测试消息。校验值见 [SHA256SUMS](SHA256SUMS)。不要在聊天或仓库提供真实 API Key 或连接口令。

当前聊天工具没有附件上传能力，因此用仓库内的小型安装包提供可下载交付；后续 APK 可通过成功的 GitHub Actions 构建产物分发。
